## Post Content

Introducing YaTTI - Yayasan Teknologi Terbuka Indonesia (Indonesian Open Technology Foundation).

Founded in 2013, we build open-source tools that make knowledge more accessible. Based in Indonesia, working globally.

**What we do:**
We develop AI-powered research knowledgebases and developer tools - all freely available.

**What's coming:**
- Specialized knowledgebases for research and professional use
- Public API access for researchers to knowledgebases
- Continued work on the en_ID locale and other language tools

We believe powerful research tools shouldn't be locked behind paywalls or borders.

Follow along as we release our first public knowledgebases and open our APIs to developers worldwide.

First releases are coming soon.
